The Automated IT Service Desk & Asset Tracker is a custom Salesforce application designed to improve the management of IT support requests and company IT assets. The project simulates a real-world IT Service Desk environment where employees can submit support requests, technicians can manage and resolve issues, and administrators can monitor service performance through automation, reports, and dashboards.

The application enables organizations to maintain an inventory of IT assets assigned to employees while providing a structured process for handling hardware, software, network, and access-related issues. Using Salesforce automation, the system automatically calculates SLA due dates, assigns technicians, sends email notifications, and monitors overdue service requests, reducing manual effort and improving service efficiency.

The solution was built using Salesforce's declarative (clicks, not code) capabilities to demonstrate core Salesforce Administrator skills. It incorporates custom objects, object relationships, validation rules, formula fields, Flow automation, Lightning App Builder, security configuration, reports, dashboards, and user interface enhancements to create a complete business application.
