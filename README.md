Project Overview

As part of my Salesforce Administrator learning journey, I developed the Automated IT Service Desk & Asset Tracker in a Salesforce Developer Edition to gain practical, hands-on experience with real-world business processes.

The idea behind this project was to create a system that helps an organisation manage its IT assets and support requests in one place. Employees can log IT issues such as hardware problems, software installation requests, network issues, or access requests, while technicians can manage, track, and resolve these requests efficiently. At the same time, the organisation can keep track of IT assets assigned to employees, including computers, laptops, printers, and other equipment.

To make the application more realistic, I automated several business processes using Salesforce Flow. When a service request is created, the system automatically assigns a technician, calculates the SLA due date based on the ticket priority, and sends email notifications. A scheduled flow also runs daily to identify overdue tickets and send reminder emails to technicians, helping the IT team stay on top of unresolved issues.

I also implemented Salesforce security features such as roles, permission sets, and sharing rules to ensure users only have access to the information relevant to their role. Managers can monitor team performance through custom reports and dashboards, providing visibility into ticket volumes, resolution status, SLA compliance, and asset allocation.

The application was built entirely using Salesforce's declarative tools without writing Apex code. It includes custom objects, lookup and master-detail relationships, validation rules, formula fields, record-triggered flows, scheduled flows, dynamic forms, Lightning record pages, reports, dashboards, and a guided Screen Flow for creating service requests.

This project allowed me to apply the concepts I learned through Trailhead in a practical scenario while strengthening my understanding of Salesforce administration, automation, security, and user experience. It also serves as a portfolio project to demonstrate my ability to design and build a complete Salesforce solution that addresses real business requirements.
